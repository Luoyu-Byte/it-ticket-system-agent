# 工单系统 V1 交互原型

本目录归档需求评审阶段的页面草图，不是正式前端工程。

## 打开方式

使用 Edge 或 Chrome 打开本目录下的 `index.html`，无需安装项目依赖或启动后台。

- 顶部“预览身份”可切换员工、工程师和管理员，仅用于演示，不是真实登录。
- 可以浏览列表、创建示例工单、派单、追问、提交解决说明、确认关闭，以及查看账号管理布局。
- 数据仅保留在当前页面内，刷新或重新打开后恢复示例数据。
- 不要填写真实账号密码、员工名单或敏感业务信息。
- 真实登录、Excel 导入、附件上传及后端权限和持久化均未实现。
- 会话内的可选设计调节控件在独立浏览器中不提供；角色切换与工单模拟操作仍可使用。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| index.html | 已导出的完整浏览器预览入口 |
| it-service-desk.source.html | 可编辑的原始 HTML/CSS/JavaScript 草图片段，导出入口的来源 |

优先维护本目录的源文件，修改后重新导出 `index.html`；会话预览只作为展示副本，避免两份内容各自修改。

项目根目录的《工单系统_V1页面设计与评审记录.md》记录页面方案、规则映射和此前验证范围。后续正式前端与 Spring Boot 后端另建工程，不直接将本原型的内存模拟逻辑当作生产实现。
